Setup Guide

How It Works

Transfer files seamlessly in five simple steps without plugging in any cables.

01

1. Installation

Download and install the BNet.Mobile.FTPServer application directly on your Android phone.

02

2. Network Connectivity

Connect both your phone and PC to the same local Wi-Fi router or create a Mobile Hotspot.

03

3. Start Service

Tap the Start button in the app to launch the server and generate your custom ftp:// address.

04

4. PC Connection

Open Windows File Explorer or any standard FTP client (like FileZilla) and type in the displayed address.

05

5. Seamless File Transfer

Upload, download, or edit files directly between your device and desktop. Stop the FTP service whenever you are finished with a single tap.
